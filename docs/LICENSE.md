# License

OpenGeoResearch is licensed under the Apache License, Version 2.0.

## Why Apache 2.0?

OpenGeoResearch aims to be:

- Open source
- Community driven
- Research focused
- Institution friendly

Apache 2.0 provides:

- Freedom to use
- Freedom to modify
- Freedom to distribute
- Freedom to commercialize
- Patent protection for contributors and users

This makes it suitable for:

- Universities
- NGOs
- Governments
- Research Institutes
- Private Organizations

# Third-Party Dependencies

OpenGeoResearch uses third-party libraries.

Each dependency retains its own license.

Project maintainers should:

- Track dependency licenses
- Avoid incompatible licenses
- Maintain a THIRD_PARTY_LICENSES.md file
