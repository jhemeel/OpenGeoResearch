# OpenGeoResearch
Open-source research data collection and geospatial analytics platform.

# Vision Statement
OpenGeoResearch is an open-source platform that enables researchers, NGOs, public health professionals, and academic institutions to collect, manage, analyze, and visualize research data using modern web technologies and geospatial analytics. The platform combines survey management, GPS-enabled data collection, choropleth mapping, heat mapping, and statistical reporting in a unified system.
